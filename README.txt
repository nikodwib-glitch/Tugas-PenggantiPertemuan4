SOLEHUB — PROYEK TUGAS PENGGANTI PERTEMUAN KE-4

Tema: Toko sepatu online
Framework: Bootstrap 5.3.3 + CSS sederhana

CARA MENJALANKAN
1. Ekstrak folder proyek.
2. Buka index.html di browser. Bootstrap dan foto produk tersedia secara lokal.
3. Tombol menu bekerja pada layar kecil. Tombol produk menambah jumlah keranjang, dan form menampilkan pesan konfirmasi.

STRUKTUR
- index.html               halaman utama
- css/bootstrap.min.css    Bootstrap 5.3.3
- css/style.css            gaya sederhana dan aturan responsif
- js/script.js             menu, keranjang, dan form
- img/                     foto produk lokal
- screenshots/             screenshot desktop, tablet, dan mobile
- laporan.pdf              laporan dan screenshot tampilan
